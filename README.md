# Fintrox.Client

Frontend repository for the Fintrox accounting platform.

## Target

- Next.js 16 App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Generated API client from Fintrox.Server OpenAPI

## Migration state

The existing .NET/Blazor code is temporarily retained as legacy reference while functionality is migrated to the new Next.js client. It is not the target architecture.
