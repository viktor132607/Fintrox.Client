# Experience composition

Structure only. Three presets share one application and reusable module UI.
Only composition connects this layer to public module entry points; Experience itself may import shared code and its own files. No imports of business modules, app routes or composition.
All reusable widget contracts belong to shared/types when implemented. Layout configuration contains stable IDs, not executable code.
Accountant is the canonical ID for the earlier Professional/mid description; Custom is a saved override, not a fourth security role.
